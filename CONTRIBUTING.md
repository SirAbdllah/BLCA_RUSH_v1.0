# Contributing / المساهمة

Contributions are welcome under the MIT license in `LICENSE`.

1. Keep the core dependent only on vanilla Arma Reforger. Put optional integrations in separate add-ons.
2. Keep authoritative checks on the server: player ownership, team, distance, objective state, spawn safety, and ticket reservations.
3. Preserve resource GUIDs when editing existing resources. Assign fresh GUIDs to new resources.
4. Run the Workbench survey and a dedicated-server test after changes to rules, RPCs, spawning, or objectives.
5. Include a short reproduction, expected behavior, actual behavior, game version, and relevant log excerpt for bug reports. Remove account identities, passwords, tokens, and private server addresses.
6. Update Arabic and English documentation when configuration or behavior changes.

المساهمات مرحب بها وفق رخصة MIT. حافظ على استقلال الطور واعتماده على اللعبة الأساسية، واجعل أي تكامل إضافي في مود منفصل. تحقق من الأذونات وحالة الهدف والرسبون على السيرفر، واحتفظ بمعرّفات الموارد الحالية. أرفق خطوات إعادة المشكلة وإصدار اللعبة واللوق المناسب بعد إزالة البيانات الخاصة، وحدّث الدليلين عند تغيير الإعدادات.
